# 木偶人（Puppet）

木偶人是基于 Godot + C++ 的独立角色骨骼动画制作软件项目，工程目录名为 Puppet。当前已实现标准人形骨架的姿势编辑、关键帧制作、自动过渡、播放、本地动作库，以及 MCP 动画编辑与多视角截图接口；现已提供角色模型导入、独立绑定项目、关节与骨长调整、自动蒙皮和只读动画预览；批量导出按后续阶段开发。

本目录是软件项目根目录。窗口标题为“木偶人”，可以直接双击根目录的 **木偶人.exe** 启动独立界面。

界面采用紧凑工作台布局：左侧为图标导航、骨骼列表和动画库，中间为工具与骨骼视口，右侧为细节面板。保存、撤销和播放等操作集中在底部动画制作面板；窗口缩放时中央视口自动伸展，两侧面板可收起或一键恢复。

顶部“设置”提供字体大小与界面缩放：字号 12–24 像素、界面缩放 75%–200%，默认 16 像素与 100%。修改即时生效，偏好自动保存至 `workspace/settings.cfg`。

设置页的“AI 与 MCP”提供本机服务开关、连接状态，以及通用 JSON 和 Codex TOML 连接配置复制。服务默认启用，只监听本机；AI 客户端通过项目内 Python stdio 适配器接入。完整配置、工具和骨架扩展约定见 [MCP 使用说明](docs/MCP使用说明.md)。

## 运行与构建

- 本机已下载 Godot 4.7.2，位于 `tools/Godot`，并已编译 C++ 扩展和项目启动器。
- 双击 `木偶人.exe`，或在 PowerShell 7 中执行 `./scripts/启动.ps1`。
- 打开 Godot 编辑器：`./scripts/启动.ps1 -Editor`。
- 重新编译 C++ 与启动器：关闭木偶人后执行 `./scripts/构建.ps1`。
- 新环境准备：安装 Git、Python 和 Visual Studio C++ 桌面工具后执行 `./scripts/准备环境.ps1`。
- 引擎与扩展版本固定在 `dependencies.lock.json`；C++ 绑定使用兼容的 4.5 API，已在 Godot 4.7.2 中验证加载和运行。
- `木偶人.exe` 是项目便携启动入口，调用本目录的 Godot 环境；迁移软件时保留工程文件、`bin` 和 `tools/Godot`。

常用操作和保存位置见[首版使用说明](docs/首版使用说明.md)。

## 源码仓库与已有数据

仓库保留当前有效源码、构建脚本、依赖版本说明、项目文档及以下工作数据：

| 目录 | 保存内容 |
| --- | --- |
| `app/`、`native/`、`launcher/`、`mcp_service/` | Godot 界面、C++ 动画核心、Windows 启动器和 MCP 服务源码 |
| `workspace/animations/` | 8 份已有动画：基础站姿、挥手示例、下蹲示例、走路循环、奔跑循环、跳跃、站立转持盾弓步防御、拄杖站立转前指施法 |
| `workspace/bindings/` | 已有角色绑定项目及自包含的模型资源 |
| `workspace/imports/` | 角色源模型及配套贴图 |
| `workspace/rigs/` | 自定义骨架定义（添加后纳入版本管理；标准人形由程序内置） |
| `workspace/previews/` | 5 套动画制作脚本、对应动作标识和关键姿势规划 |

Godot 导入缓存、工具安装目录、第三方依赖副本、编译产物、历史备份、预览截图、操作日志、本机偏好和 MCP 运行会话不进入仓库。绑定项目中的 `source_path` 记录最初导入位置；重新打开项目使用同目录的 `模型_00.res`，不依赖原机器路径。

新机器克隆仓库后，在项目根目录的 PowerShell 7 中执行：

```powershell
./scripts/准备环境.ps1
./scripts/启动.ps1
```

准备环境需要先安装 Git、Python 和 Visual Studio C++ 桌面开发工具；脚本会恢复固定版本依赖并生成运行程序。已有动画会从 `workspace/animations/` 自动读取，角色绑定项目可在绑定工作区选择。MCP 客户端连接示例中的绝对路径需替换为当前克隆位置，也可从软件设置页复制当前配置。

## 完整产品规划

- 木偶控制：关节旋转限制、FK（正向运动学）、手脚 IK（逆向运动学）、接触和握持。
- 动画制作：关键帧、自动过渡、曲线、循环、根运动、姿势库和动作库。
- 角色适配：无骨骼模型的定位、骨架生成与蒙皮，以及已有骨架角色的动作重定向。
- AI 接口：读取骨架、批量编辑、结果诊断、多视角预览、撤销和后台任务。
- 批量导出：GLB/FBX 预设、角色与动作组合、任务队列、结果清单和 UE 接入验证。

## 技术与项目约定

- Godot 负责界面与三维预览，独立 C++ 核心负责动画数据和求解，使用 GDExtension 接入。
- 手动操作与 AI 共用动画库、文档修订、撤销历史和 C++ 求解；后续工具复用文档命令，导出也将接入同一求值流程。
- 用户可编辑的长度、时间按米和秒输入显示，并保留两位小数；按帧定位和输出采样使用精确时间码。
- 新增函数、类型和属性添加中文注释；用户可见名称使用简短中文。
- LxARPG 作为首个 UE 动画接入验证项目；Puppet 核心按独立软件组织。
- Godot、godot-cpp 和格式组件的准确版本与依赖在 P0 验证后固定。

## 开发顺序

P0 技术验证 → P1 木偶控制 → P2 关键帧动画 → P3 AI 编辑 → P4 已有骨架适配 → P5 无骨架绑定 → P6 批量导出 → P7 首版稳定。

阶段交付和简短验收统一维护在[开发计划](docs/开发计划.md)中，功能变更同步更新[功能设计](docs/功能设计.md)。
