# 角色绑定

进入顶部 **角色模型** 页面。现已支持 GLB、glTF、FBX 运行时导入，模型材质和纹理随绑定项目一起保存。导入已有骨架的模型时，本版把几何作为新绑定任务的参考模型；不继承原有权重或自带动画。

## 日常流程

1. 点击 **导入模型 · 新建项目**，或把模型文件拖入角色页面。ZIP 请先解压，并保持 FBX 与配套 `.fbm` 贴图目录的相对位置。导入前可选择源骨架。
2. 新任务按模型高度放置参考骨架。模型朝向不同，可用 **骨架左转 90°／右转 90°** 调整整套骨架。
3. 左键拖动绿色关节；右侧也可输入 X、Y、Z 或与父关节的距离。长度单位为米，输入显示两位小数。改变骨长不会缩放角色模型。
4. 默认只移动当前关节，其余关节停在原位置。勾选 **移动时带动子关节** 可平移子链；直接修改骨长始终带动后代。
5. 点击左下方任意动画立即预览。可以暂停或拖动秒制进度条；没有动画编辑或关键帧写入操作。
6. 点击 **返回绑定姿态**，恢复原模型与参考骨架，再继续调整。预览中骨骼没有放好导致的扭曲不会留在模型上。

右键旋转视角，Shift＋右键平移，滚轮缩放。上方提供透视、正面、侧面、背面和俯视；也可通过 MCP 设置任意偏航、俯仰、距离和观察中心。

关节球会透过模型显示，便于选择身体内部的骨骼。右侧可把拖动限制到 X、Y、Z 单轴；轴线正对摄像机时，换一个观察方向或直接输入坐标。

## 项目保存

- 每个任务位于 `workspace/bindings/<项目ID>/`，中文名称保存于 `项目.json`。
- 项目包含自己的参考骨架、关节位置、骨长、蒙皮模式，以及自包含的模型、材质和纹理资源。
- 修改自动保存；拖动松开时保存一次，可独立撤销／重做。项目名称也可编辑并保存。
- 下拉框可以随时重开任何已保存项目；下次启动会恢复最近项目。
- 原模型文件移动后仍可使用项目副本。请备份整个项目文件夹；只复制 `项目.json` 不包含网格和纹理。
- 只要项目目录保留，就可以继续调整。撤销历史限当前打开会话的 64 次修改；长期保留的是已保存结果。

Ctrl＋S 保存项目，Ctrl＋Z 撤销，Ctrl＋Shift＋Z 或 Ctrl＋Y 重做，空格播放／暂停，Esc 返回绑定姿态。这些快捷键在角色页面不会编辑源动画。

## 原始模型与动画

原始几何在导入后独立保存。编辑参考关节只修改项目骨架；动画预览通过当前参考姿态的逆绑定矩阵驱动一个临时蒙皮网格。返回绑定姿态直接显示原始网格，预览不会烘焙到模型中。

动画预览会根据源骨架和绑定骨架的实际骨段方向，自动补偿 T 字姿态与自然下垂姿态之间的差异。已经摆成下垂姿态的手臂不会再次叠加源动画的下压角度。转换只用于播放，保留当前项目骨长、已保存关节位置和源动画；界面蒙皮、骨架线、MCP 姿势回读与截图共用同一转换结果。

不同绑定项目互不改变骨长，也不会改变骨架库。动画来自所选骨架的动作库，预览读取动画快照，不保存关键帧；MCP 在角色工作区同样拒绝动画写入。需要制作动作时回到 **骨骼动画** 页面。

默认使用 **沿模型表面传播的四权重自动蒙皮**，也提供单权重刚性预览。自动算法从骨段附近的真实表面播种，沿三角形连接传播权重；UV 缝共享拓扑，衣物与手臂之间的空隙不会直接传播权重。躯干支持多层衣物，小型独立配件采用整体归属，邻接平滑减少突变。特殊的焊死网格、复杂服装仍可手工修正；这不是布料物理模拟，也不新增衣摆骨骼。

## 权重查看与修改

右侧切换到 **蒙皮权重** 页签。

1. 在左侧选择骨骼，模型显示该骨骼的权重热图：蓝色为 0，红色为 1，过渡色表示部分影响。关闭热图可恢复贴图。
2. 左键点击模型表面，以命中顶点为中心沿网格表面选择一片区域。半径使用米、两位小数；选区提亮，面板显示顶点地址和所有影响骨骼的百分比。
3. 可设置、增加、减少当前骨骼权重，或沿表面平滑。修改后自动归一化，最多保留四根骨骼影响，UV 缝上的对应顶点同步修改。
4. 衣服被手臂带走时，选中那片衣物，选择 **清除选区的手臂影响**，把接收骨骼设为合适的骨盆、腰部或胸部，再点击 **应用到选区**。只转交手臂权重，其他影响保留。
5. 可以在动画暂停时点选变形后的表面；应用权重后保留同一个动画观察时刻，立即查看变化。返回 **关节设置** 页签恢复关节拖动。
6. **选区恢复自动权重** 只清除所选区域的手工覆盖；**重新计算自动蒙皮** 保留全部手工覆盖、关节位置和骨长。

勾选 **选择整个连通表面** 会选中所有相连三角面，有些模型的袖子与外套属于同一连通表面，请以实际提亮范围为准。每次应用作为一次操作自动保存，可撤销、重做，重开项目后仍可修改。手工权重以稳定顶点和骨骼标识保存于该项目的 `weight_overrides` 中，原模型与动画文件保持原样。

## MCP

绑定工具现共 20 个，加上骨骼动画工具总计 44 个（接口版本 1.2）。更新后重新连接 MCP 可刷新工具列表。先调用 `get_document`、`list_binding_projects`，再用稳定的 `project_id` 定位任务。

| 工具 | 用途 |
| --- | --- |
| `list_binding_projects` | 列出所有保存项目 |
| `get_binding_project` | 读取项目、参考关节位置、骨长、相机和播放状态 |
| `create_binding_project` | 导入本机模型并新建任务 |
| `open_binding_project` | 打开已有任务 |
| `move_binding_joint` | 指定关节位置，选配子链平移 |
| `set_binding_bone_length` | 调整骨长并移动后代 |
| `update_binding_project` | 修改名称、蒙皮模式或骨架朝向 |
| `save_binding_project` | 显式保存 |
| `undo_binding_edit` / `redo_binding_edit` | 独立撤销／重做 |
| `preview_binding_animation` | 播放或定位只读动画 |
| `stop_binding_preview` | 返回原模型及参考姿态 |
| `evaluate_binding_pose` | 回读项目骨长下的真实关节位置和四元数 |
| `set_binding_view` | 设置角色工作区摄像机 |
| `render_binding_preview` | 独立相机截图，返回 PNG、关节像素投影、时刻及修订；`weight_bone_id` 可截图权重热图 |
| `get_binding_weights` | 分页读取真实权重、原始坐标和是否手工覆盖，支持骨骼阈值或选区过滤 |
| `set_binding_weight_view` | 查看单根骨骼热图及选区，不写入项目 |
| `edit_binding_weights` | 设置、增减、平滑、清除指定骨骼或全部手臂影响 |
| `reset_binding_weights` | 选区恢复自动权重；显式 `scope=all` 才恢复全项目 |
| `recalculate_binding_weights` | 重算自动权重，保留关节位置、骨长与手工覆盖 |

写入使用现有的 `document_id`、`expected_revision`、唯一 `request_id`；已执行请求重放不会重复新建项目。拖动期间拒绝外部项目命令，防止 AI 与手动拖动相互覆盖。

例如先读取最新文档修订，再移动当前项目中的左手：

```json
{
  "project_id": "从项目列表取得的ID",
  "document_id": "从当前文档取得的ID",
  "expected_revision": 12,
  "request_id": "本次唯一请求ID",
  "bone_id": "hand_l",
  "position_m": [0.10, 0.55, -0.20],
  "move_children": false
}
```

权重的顶点标识形如 `0:0:2146`，依次为原始网格、表面、顶点索引。先用 `get_binding_weights` 查询；修改选区使用 `vertex_ids`，或者 `seed_vertex_id` 加 `radius_m`（可选 `whole_component`）。例如 `edit_binding_weights` 设置 `operation=exclude_arms`、`fallback_bone_id=pelvis`，将选区的手臂影响转交骨盆。修改所需文档修订来自 `get_document`，不是项目自己的 `project_revision`。重算和权重修改都沿用绑定项目撤销历史。

截图支持 `view.yaw_deg`、`view.pitch_deg`、`view.target_m`、`view.distance_m`、正交投影及关节特写。不传 `clip_id` 显示原模型；传入动画和 `time_seconds` 则显示该时刻的蒙皮结果。截图使用独立场景，不改变用户正在观察的视角。

## 功能列表与权重涂抹

角色模型工作台最左侧提供“骨骼绑定”和“蒙皮权重”。第二列显示当前功能配置、骨骼树和所属骨架的动画；中央观察角色，右侧显示关节设置或权重修正工具。

- 骨骼绑定：选择源骨架，在树中选择关节，拖动模型中的红色关节点调整绑定位置。切换源骨架会按模型高度重新适配，并清除旧骨架的手工权重；可以撤销恢复。
- 蒙皮权重：选中骨骼后自动显示蓝色（0）至红色（1）的权重热力图。选择增加、降低或平滑笔刷，设置半径（米，两位小数）与强度，在模型表面按住左键拖动。涂抹暂停并保持当前动画姿态，沿相连表面选区，笔刷边缘渐弱。
- 松开鼠标自动保存整笔修改；一次撤销撤回整笔。右键旋转视角，Shift＋右键平移，滚轮缩放。降低权重时，右侧“降低／清除权重转交给”选择接收骨骼，默认胸部；减掉的份额直接转交，不再按比例放大其他骨骼。
- “保留涂抹 · 重算平滑边界”固定已有手工权重，重算自动解，并将周围三圈邻接顶点进行八轮平滑，形成过渡。操作可以撤销。
- “重新计算自动蒙皮”只更新自动解并保留全部手工覆盖；“选区恢复自动权重”清除当前选区的手工覆盖。

胸口或衣物仍被肩部牵拉时，单根上臂的蓝色热图不能排除锁骨、前臂等其他影响。可使用“清除肩臂影响（含锁骨）”，将接收骨骼设为胸部，仅涂抹需要修正的胸口表面，再平滑边界。该操作包含两侧锁骨及手臂子链，避免涂到袖子。
