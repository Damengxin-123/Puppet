# 木偶人 v0.1.0 使用说明

2026-10-22 更新：角色绑定现已支持沿网格表面传播的自动蒙皮、权重热图、表面选区、权重修改与手臂影响清除；关节、模型和源动画保持独立。绑定相关 MCP 工具共 20 个，总计 44 个。操作、数据隔离、限制和验证结果见[角色绑定使用说明](角色绑定使用说明.md)。已有模型权重导入、连续涂抹画笔、布料模拟及导出仍待后续开发。

已加入 MCP 动画编辑接口、骨架注册与约束扩展、多视角截图。设置页提供“AI 与 MCP”开关、连接状态及配置复制；左侧骨骼菜单可以切换后续注册的骨架。完整工具、接入配置和数据格式见 [MCP 使用说明](MCP使用说明.md)。

本版提供独立桌面窗口，标题为“木偶人”。根目录 `木偶人.exe` 为项目启动入口，使用 `tools/Godot` 中已安装的运行环境。

## 当前界面

- 顶部功能栏：骨骼动画、角色模型、设置。当前实现骨骼动画及字体、界面缩放设置；角色模型显示后续功能说明。
- 最左侧图标栏：骨架预览、动画制作，以及底部的专注视口按钮；鼠标悬停显示功能名称。
- 视口上方工具栏：选择与拖拽、旋转关节、观察视角、聚焦骨架、网格和两侧面板显隐按钮。
- 视口左侧资源栏：只读骨骼层级与当前骨架的动画库，支持切换、新建和重命名。
- 中央视口：固定标准人形骨架，内部为粗线与关节点，外部为半透明球体和圆柱体。
- 视口右上角：“外壳”滑块实时调整视觉外壳透明度，0% 为不透明，100% 为完全透明，默认 80%；本次运行中切换骨架或动画时保留当前值，调整不修改姿势或动画数据。
- 视口右侧细节面板：显示选中关节的三轴旋转及真实活动范围；展开“角色根位移 / 米”可继续修改角色整体位置，也可切换骨骼核心与半透明模型的显示。
- 视口下方动画制作面板：动画名称、撤销、重做、保存、关键帧记录与删除、横向关键帧列表、秒制轨道、逐帧前后定位、播放、速度、循环与时长。“更多”图标中保留自动关键帧和过渡方式。

窗口按实际可用空间排布，放大、最大化或改变长宽比例时不会出现固定画布留下的黑边。软件根据字号、界面缩放和可用宽度自动收起侧栏，仍可通过工具栏右端的图标重新打开。窄窗口中打开一侧面板会收起另一侧，为视口保留空间。最小窗口尺寸为 900×620。

点击左下角“专注视口”可临时收起两侧面板，再次点击恢复原有状态。切换到“骨架预览”会暂停播放并收起底部动画制作面板。

## 字体与界面缩放

打开顶部“设置”，在“显示与缩放”中调整：

- 字体大小：12–24 像素，默认正文字号为 16 像素。标题、正文、辅助文字、关节树、输入框和时间刻度保持相对字号层级。
- 界面缩放：75%、100%、110%、125%、150%、175%、200%，默认 100%。文字、按钮、图标和菜单一起缩放。
- 效果预览：直接观察当前文字及按钮大小；“恢复默认”还原为 16 像素、100%。

调整即时生效，并自动保存到 `workspace/settings.cfg`，下次启动恢复。字号与界面缩放可以组合使用，例如 18 像素配合 125%。进入设置和调整外观会保留当前未记录姿势、动画、时间位置及撤销记录。

较大缩放下，动画操作按钮自动换行，工作区可滚动查看；顶部功能导航始终保留，便于回到设置调节。测试使用隔离的设置文件，不会修改个人显示偏好。

## 第一次制作动画

1. 双击根目录 `木偶人.exe`。首次运行会生成基础站姿、挥手、下蹲三个示例。
2. 从左侧进入“动画制作”，在动画库右上角点击“＋”新建动作。
3. 点击时间轨道上的任意位置，确定要记录姿势的时刻。
4. 点击视口中的关节点，或从左侧关节列表选择部位。
5. 使用视口上方“选择与拖拽”拖动手脚，或使用“旋转关节”的彩色环、右侧数值框调整姿势。
6. 点击底部带加号菱形图标的“关键帧”按钮。当前位置的全身姿势会被记录，并立即写入本地动作文件。
7. 改变时间点并记录更多关键帧；上方卡片自动按时间排序。
8. 点击底部播放图标查看过渡，可直接调整速度、循环和时长；保持/线性/平滑模式位于动画面板右上角“更多”菜单。

同一个时刻再次记录会更新该关键帧。直接点击已有关键帧卡片可继续编辑；拖动时间轨道上的菱形可以移动关键帧时间，已有帧的时刻不会被静默覆盖。

姿势没有记录时显示“姿势待记录”。切换动作、时间或退出时，会提供记录后继续、放弃或留在当前姿势的选择。也可以在动画面板“更多”菜单中开启“自动关键帧”，在一次姿势调整结束时自动记录。

## 骨架与姿势

- 当前预设为标准人形，包含根节点在内共 23 个节点。
- 骨架层级、骨骼长度和绑定位置固定；用户修改的是关节旋转和角色根位移。
- 拖动手脚时，C++ 求解器调整短骨链的旋转，不会把肢体拉长。
- 当前关节限制采用局部三轴范围，输入框会显示允许区间；完整人体摆动锥、全身 IK 和脚部接触固定属于后续功能。
- 当前关键帧记录完整身体姿势；按骨骼拆分的精细轨道和曲线切线编辑后续增加。

## 时间与播放

- 时间输入与显示采用秒，保留两位小数。内部使用每秒 60000 刻度，按帧定位不累加舍入误差。
- 默认动作时长为 2.00 秒，可在轨道旁修改。
- 缩短时长前应先移动或删除区间之外的关键帧，避免意外丢失动作。
- 中间帧由 C++ 四元数插值生成，无需逐帧手动记录。
- 速度选项为 0.25、0.50、1.00、1.50 和 2.00 倍，不改变保存的动作时长。

## 视口操作与快捷键

| 操作 | 效果 |
| --- | --- |
| 左键点击关节 | 选中并显示细节 |
| 拖拽工具下拖动关节 | 调整姿势，保持骨长 |
| 旋转工具下拖动彩色环 | 调整对应旋转轴 |
| Shift 配合旋转 | 精细调整 |
| 右键或中键拖动 | 环绕观察 |
| Shift + 右键/中键 | 平移观察 |
| 滚轮 | 缩放观察 |
| W / E / Q | 切换选择拖拽 / 关节旋转 / 观察视角 |
| F | 恢复透视观察 |
| 空格 | 播放或暂停 |
| Ctrl + S | 保存动画；未记录姿势会先写入当前关键帧 |
| Ctrl + Z / Ctrl + Shift + Z（或 Ctrl + Y） | 撤销 / 重做 |
| Delete | 删除当前关键帧，至少保留一个姿势 |

## 动作保存

默认目录为项目内的 `workspace/animations/standard_humanoid_v1/`。每段动画使用稳定 ID 保存为 JSON，包含骨架标识、关节顺序、关键帧时间码、局部旋转、根位移和播放配置。

动画名称与文件 ID 分开，重命名不会改变骨架索引。保存使用临时文件并保留 `.previous` 上一版；若中断导致主文件缺失，下次载入会尝试恢复上一版。

工具、编译缓存和用户动作目录已从 Godot 扫描及源码版本规则中隔离。备份自制动作时，复制 `workspace/animations` 目录。

## 开发与简单验收

- 编辑器：PowerShell 7 执行 `./scripts/启动.ps1 -Editor`。
- 编译：关闭正在运行的木偶人，再执行 `./scripts/构建.ps1`。
- 新环境准备：执行 `./scripts/准备环境.ps1`，按锁定版本下载依赖并编译。
- 简单验收入口为 `scripts/验收.gd`，用隔离动作目录验证一次完整工作流程。
- 当前验收结果及不同窗口尺寸、字号和缩放的实际渲染截图保存在 `build/verification/`，不写入用户动画库。21 项简单验收覆盖动画流程、侧栏收放、设置保存与重读、最大缩放、恢复默认和 125% 缩放下的实际关节拖动。

Godot 版本为 4.7.2；C++ 绑定固定为 `godot-4.5-stable`，扩展最低兼容版本 4.5，并已在实际 4.7.2 运行环境中验证。
